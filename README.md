## Features
- Dashboard analytics (Students, Internships, Applications, Offer letters)
- Manage internship postings and domains
- Review student applications and change progression status
- Generate, upload, and certify student credentials and offer letters
- Inquiries & contact messages manager
- Platform & library settings

## Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the dev server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
